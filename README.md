# ⚽ FFIB 2.0 — Frontend

Frontend oficial de **FFIB 2.0**, la nueva plataforma SaaS desarrollada por **SportsTech Labs** para modernizar la gestión de federaciones deportivas.

---

## 🚀 Descripción

Este repositorio contiene la aplicación web desarrollada con **Next.js**, ofreciendo una experiencia moderna, rápida y responsive para:

- Público general
- Clubes
- Jugadores
- Árbitros
- Entrenadores
- Administradores

La aplicación consume la API REST proporcionada por `ffib-backend`.
